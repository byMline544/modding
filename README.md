# TechnoCloud (MCP 7.51 / Forge 7.8.1.737)

Стартовая архитектура технологического мода для Minecraft 1.5.2.

## Текущий шаг (Этап 10)
- Сохранены машины, кабельные классы и пакетный слой предыдущих этапов.
- Расширены сетевые GUI-режимы:
  - Генератор: ECO / TURBO
  - Зарядник: SAFE / FAST
  - Экстрактор: STD / OVC + автоимпорт/автовывод
  - Сборщик: NORMAL / PRECISE + автоимпорт/автовывод
- `PacketIds` и `PacketHandler` расширены новыми действиями переключения авто-входа/выхода.
- `TileEntityExtractor` и `TileEntityAssembler` получили флаги `AutoInput`/`AutoOutput`, NBT-сохранение и серверную логику переноса предметов:
  - автоимпорт берёт 1 предмет с западной стороны (x-1)
  - автовывод кладёт 1 предмет на восточную сторону (x+1)
- `ContainerExtractor` и `ContainerAssembler` синхронизируют новые флаги на клиент через `sendProgressBarUpdate`.
- `GuiExtractor` и `GuiAssembler` получили дополнительные кнопки `IN`/`OUT` с отправкой пакетов на сервер.
- Обновлена книга новичка.

## Структура
- `tcw.MainLoader` — основной загрузчик.
- `tcw.managers` — все реестры и инициализация.
- `tcw.items` — предметы, батареи и инструменты.
- `tcw.blocks` — руды, машины, солнечные панели, кабели.
- `tcw.energy` — API и хелперы энергосети.
- `tcw.tiles` — tile entity машин/панелей/кабелей.
- `tcw.world` — генерация руд.
- `tcw.gui`, `tcw.book` — GUI и контент книги.
- `tcw.achievements` — достижения.
- `tcw.packets` — сетевой обработчик.
- `tcw.proxy` — client/server proxy.
