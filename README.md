# TechnoCloud (MCP 7.51 / Forge 7.8.1.737)

Стартовая архитектура технологического мода для Minecraft 1.5.2.

## Текущий шаг (Этап 13)
- Сохранены машины, кабельные классы и пакетный слой предыдущих этапов.
- Добавлены переключаемые стороны авто-логистики для экстрактора и сборщика:
  - поддерживаются `OFF`, `DOWN`, `UP`, `NORTH`, `SOUTH`, `WEST`, `EAST`
  - отдельно для входа и выхода
- `PacketIds` и `PacketHandler` расширены действиями циклического переключения входной/выходной стороны.
- `TileEntityExtractor` и `TileEntityAssembler` теперь сохраняют `InputSide`/`OutputSide` в NBT и используют выбранные стороны для автоимпорта/автовывода.
- `ContainerExtractor` и `ContainerAssembler` синхронизируют side-режимы на клиент через `sendProgressBarUpdate`.
- `GuiExtractor` и `GuiAssembler` получили кнопки `IN< ...` / `OUT> ...` для смены сторон.
- Полная адаптация к MCP 7.51 / Forge 7.8.1.737 (Minecraft 1.5.2):
  - убраны несовместимые вызовы `setTextureName` и `setHarvestLevel`;
  - текстуры переведены на `registerIcons("technocloud:...")`;
  - для руд выставлены harvest-уровни через `MinecraftForge.setBlockHarvestLevel`.
- Исправлен жизненный цикл загрузки мода:
  - `@Mod` использует стабильный `modid = "technocloud"`;
  - `@PreInit/@Init/@PostInit` используют сигнатуры с FML event-параметрами.
- Добавлена отдельная вкладка креатива `TechnoCloud` и на неё перенесены предметы/блоки мода.
- Добавлены русские подписи и локализация вкладки `itemGroup.technocloud` через `LanguageRegistry`.
- Добавлены базовые текстуры для блоков, предметов, GUI и брони в `/mods/technocloud/textures/*`.
- Авто-логистика расширена фильтрами и приоритетами:
  - Экстрактор: режим фильтра `ВЫКЛ / БЕЛ / ЧЕР` для автоимпорта;
  - Сборщик: режим фильтра `ВЫКЛ / БЕЛ / ЧЕР` + приоритет заполнения входов `СЛОТ1 / СЛОТ2`.
- Добавлены новые сетевые пакеты, NBT-сохранение и GUI-кнопки для управления фильтрами/приоритетом.
- Полировка обучающей книги и достижений: добавлены русские строки и страницы о side-режимах/фильтрах.

## Структура
- `tcw.MainLoader` — основной загрузчик.
- `tcw.managers` — все реестры и инициализация.
- `tcw.items` — предметы, батареи и инструменты.
- `tcw.blocks` — руды, машины, солнечные панели, кабели.
- `tcw.energy` — API и хелперы энергосети.
- `tcw.tiles` — tile entity машин/панелей/кабелей.
- `tcw.world` — генерация руд.
- `tcw.gui`, `tcw.book` — GUI и контент книги.
- `tcw.achievements` — достижения.
- `tcw.packets` — сетевой обработчик.
- `tcw.proxy` — client/server proxy.

## Статус релиза
Мод доведён до рабочего финального состояния для MCP 7.51 / Forge 7.8.1.737.
Остаётся только контентная полировка (арт/звук/баланс) при необходимости.

## Ветка выгрузки
Финальная выгрузка подготовлена в отдельной ветке с суффиксом `final`: `work-final`.

## Ограничение PR по бинарным файлам
- Из репозитория удалены все `.png`-текстуры, чтобы PR проходил без ошибки «Бинарные файлы не поддерживаются».
- Для восстановления текстур храните их вне PR (например, отдельным архивом/релиз-ассетом) и подключайте после мержа.

## Восстановление текстур (вне PR)
- Чтобы не получать ошибку PR «Бинарные файлы не поддерживаются», PNG-текстуры держите вне git-диффа.
- Подготовлен архив плейсхолдеров: `artifacts/technocloud-textures-pack.zip` (и `.tar.gz`).
- Распакуйте архив в корень репозитория перед локальным запуском клиента.
